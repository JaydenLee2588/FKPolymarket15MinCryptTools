# 15分钟加密货币终极操作指引 (MACD + RSI + VWAP)

## 一、 🚀 顺势多头 (Trend Following Long)
**核心逻辑：** 趋势向上，动能充足，且价格在主力成本之上。

### 1. 火箭发射 (Rocket Launch / Breakout)
* **形态：** 价格强势突破并站稳 VWAP + MACD 金叉或红柱急剧放大 + RSI 突破 55 并向上。
* **含义：** 多头刚刚发力，突破重围，动能强劲。
* **操作：** **【立即买入 (Buy)】** 概率极高，适合吃主升浪。

### 2. 空中加油 (Aerial Refueling)
* **形态：** 价格回踩 VWAP 不破 + MACD 绿柱缩短（将死不死） + RSI 回调至 45-50 后拐头向上。
* **含义：** 上涨趋势中的良性回调，主力护盘，准备第二波拉升。
* **操作：** **【逢低加仓 (Add)】** 盈亏比极佳的二次上车点。

---

## 二、 🎣 反转多头 (Reversal Long)
**核心逻辑：** 跌不动了，动能背离，价格严重偏离价值。

### 3. 底背离 (Bullish Divergence)
* **形态：** 价格创出新低 + RSI 却在抬高 + 价格远离 VWAP 下方 + MACD 绿柱缩短（价跌量缩）。
* **含义：** 卖盘枯竭，杀跌无力，准备回归均值。
* **操作：** **【左侧抄底 (Long)】** 需等待拐头确认，目标看至 VWAP。

### 4. 极度超卖 (Oversold)
* **形态：** 价格远离 VWAP 下方 + RSI < 20 + MACD 低位金叉。
* **含义：** 恐慌盘抛售殆尽，物极必反。
* **操作：** **【触底抢反弹 (Quick Long)】** 快进快出，博短线反抽。

---

## 三、 📉 顺势空头 (Trend Following Short)
**核心逻辑：** 趋势向下，动能崩坏，被主力成本压制。

### 5. 断头铡刀 (Guillotine Drop)
* **形态：** 价格有效跌破 VWAP + MACD 死叉或绿柱急剧放大 + RSI 跌破 45 向下。
* **含义：** 空头占据主导，生命线失守。
* **操作：** **【立即卖出/做空 (Short)】** 概率极高，往往伴随急跌。

### 6. 水下死叉 (Underwater Dead Cross)
* **形态：** 价格反弹触碰 VWAP 却无法突破 + MACD 在零轴下方再次死叉 + RSI 冲高不过 60 转头向下。
* **含义：** 弱势反弹结束（死猫跳），空头再次发力。
* **操作：** **【高位做空 (Short)】** 这种形态通常跌幅很深。

---

## 四、 🏃 反转空头 (Reversal Short)
**核心逻辑：** 涨过头了，动能跟不上，诱多陷阱。

### 7. 顶背离 (Bearish Divergence)
* **形态：** 价格创出新高 + RSI 却在走低 + 价格远离 VWAP 上方 + MACD 红柱缩短（价涨量缩）。
* **含义：** 典型的量价背离，买盘枯竭，惯性上涨结束。
* **操作：** **【清仓逃顶 (Sell)】** 变盘在即，大跌前兆。

### 8. 情绪高潮 (Climax Top)
* **形态：** 价格极度远离 VWAP + MACD 红柱不再增长 + RSI > 85 (严重超买)。
* **含义：** 最后的疯狂，韭菜接盘，主力出货。
* **操作：** **【暴跌警报 (Warning)】** 千万别追高，准备做空。

---

## 五、 🕸️ 震荡/陷阱 (Wait & See)
**核心逻辑：** 方向不明，指标打架，主力在洗盘。

### 9. 织布机 (Chopping)
* **形态：** 价格缠绕 VWAP 粘合 + MACD 零轴粘合 + RSI 在 45-55 之间画心电图。
* **含义：** 市场无方向，多空平衡。
* **操作：** **【休息观望 (Wait)】** 进去就是磨损本金。

### 10. 假突破 (Bull/Bear Trap)
* **形态：** 价格瞬间突破 VWAP 但角度平缓 + 无成交量配合 + RSI 刚过中轴即疲软回落。
* **含义：** 主力试盘或流动性不足。
* **操作：** **【不要追高 (Trap)】** 大概率是陷阱。

## 💡 核心观察点 (Key Takeaways)

1.  **VWAP 是生命线**：价格是在上面站稳还是在下面被压制，决定了**主趋势**是多还是空。
2.  **MACD 是油门**：是在加速踩油门（柱子变长），还是松油门（柱子变短/背离），决定了行情的**爆发力**。
3.  **RSI 是温度计**：温度适中 (50-70) 适合冲刺，温度爆表 (>80) 容易过热烧缸（回调），温度过低 (<20) 容易触底反弹。
